# Карта перевірки стану ведення учнівських зошитів

Інтерактивна карта для вчителів української мови та літератури, зарубіжної літератури, математики й англійської мови
КЗ «Василівський ліцей «Сузір'я»» (2026/2027 н. р.).

- Сторінка для вчителів: `index.html` (GitHub Pages).
- Відповіді надходять у Google Таблицю заступника директора через вебзастосунок Apps Script (`apps-script/Code.gs`):
  аркуш «Карти» — рядок на кожну карту, аркуш «Класи» — рядок на кожен клас, аркуш «Зведення» — підсумки за предметами; на пошту приходить сповіщення.
- Чернетка зберігається в браузері вчителя; повторне надсилання оновлює ту саму карту, а не дублює її.

## Як запустити

1. **Таблиця.** Створіть порожню Google Таблицю «Перевірка зошитів — відповіді вчителів».
2. **Скрипт.** У таблиці: Розширення → Apps Script. Замініть вміст `Code.gs` на файл `apps-script/Code.gs`, збережіть.
3. **Дозволи.** Оберіть функцію `setup` і натисніть «Виконати»; підтвердьте дозволи. З'являться аркуші «Карти», «Класи», «Зведення».
4. **Розгортання.** Розгорнути → Нове розгортання → тип «Вебзастосунок»; «Виконувати від імені»: Я; «Хто має доступ»: Усі. Скопіюйте адресу, що закінчується на `/exec`.
5. **Адреса в сторінці.** В `index.html` знайдіть рядок `endpoint: ''` і вставте адресу між лапками: `endpoint: 'https://script.google.com/macros/s/…/exec'`.
6. **GitHub.** Створіть репозиторій (наприклад, `zoshyty`), завантажте `index.html`, `README.md`, порожній файл `.nojekyll` і папку `apps-script`.
   Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save. За хвилину-дві сторінка буде за адресою
   `https://chabannatalya0-cpu.github.io/zoshyty/` — це посилання надсилайте вчителям.
7. **Перевірка.** Відкрийте посилання, заповніть тестову карту й надішліть: у таблиці має з'явитися рядок. Потім видаліть тестові рядки на аркушах «Карти» та «Класи».

Якщо пізніше зміните `Code.gs`, оновіть розгортання: Розгорнути → Керувати розгортаннями → редагувати → Нова версія (адреса `/exec` залишиться та сама).
